# #jointhegrid Brand Assets

## GRID symbol (canonical)

| File | Use |
|------|-----|
| `grid-symbol-light.webp` | Light backgrounds (runtime via `<GridSymbol />`) |
| `grid-symbol-dark.webp` | Dark backgrounds (runtime via `<GridSymbol />`) |
| `grid-symbol-light.png` / `grid-symbol-dark.png` | Source masters (not referenced in UI) |
| `hero-connected-ecosystem.webp` | Homepage and solution hero artwork |
| `hero-connected-ecosystem.png` | Source master for hero |

Use `<GridSymbol theme="light" />` or `<GridSymbol theme="dark" />` only.

Favicons are generated from `grid-symbol-dark.png`.

## Horizontal logos

| File | Use |
|------|-----|
| `jointhegrid-horizontal.svg` | Deprecated (placeholder geometry — use `<GridLogo />`) |
| `jointhegrid-reversed.svg` | Deprecated (placeholder geometry — use `<GridLogo reversed />`) |
| `jointhegrid-monochrome.svg` | Single-colour only |

Legacy `jointhegrid-symbol.svg` and `jointhegrid-favicon.svg` are deprecated — do not use in UI.
